================================================================================
                   🎯 INDIECLAW - QUICK START GUIDE
================================================================================

INSTALLATION (ONE-TIME, ~60 minutes):
────────────────────────────────────────────────────────────────────────────
  bash install.sh

  This installs:
    ✅ Go, Node.js, Homebrew
    ✅ RabbitMQ, Qdrant, Ollama
    ✅ Python, LLM Models (~50GB)
    ✅ Configuration files
    ✅ Startup scripts

================================================================================

EVERY DAY - START SERVICES (ONCE PER SESSION):
────────────────────────────────────────────────────────────────────────────
  ~/.indieclaw/start-services.sh

  Starts:
    🐰 RabbitMQ (5672)
    🗄️  Qdrant (6334)
    🤖 Ollama (11434)

  Wait 5 seconds for all to start.

================================================================================

RUNNING INDIECLAW (3 TERMINAL WINDOWS):
────────────────────────────────────────────────────────────────────────────

TERMINAL 1 - ORCHESTRATOR:
  cd ~/indieclaw/gateway-service
  source ~/.indieclaw/indieclaw.env
  go run ./cmd/orchestrator/main.go

  Expected log: "🚀 Orchestrator running on :9000"

TERMINAL 2 - WHATSAPP ADAPTER:
  cd ~/indieclaw/approach-road/wa-echo-loop
  source ~/.indieclaw/indieclaw.env
  npm install (first time only)
  node app.js

  Expected log: "✅ WhatsApp Bot ready!"
  Action: Scan QR code with WhatsApp

TERMINAL 3 - CONTROL PLANE (Optional):
  cd ~/indieclaw/persona-control-plane
  node server.js

  Access: http://localhost:3001
  (Edit personas without restarting)

TROUBLESHOOTING:
────────────────────────────────────────────────────────────────────────────

Model download stuck?
  Don't interrupt. Takes 30-60 mins for first time.
  Or: ollama pull qwen3:8b (manual)

RabbitMQ not starting?
  brew services restart rabbitmq
  Check: sudo rabbitmqctl status

Qdrant not connecting?
  brew services restart qdrant
  Check: curl http://localhost:6333/health

WhatsApp QR expired?
  Just restart: node app.js
  Scan new QR code

Go build error?
  go mod tidy
  go build ./cmd/orchestrator

Node modules error?
  rm -rf node_modules package-lock.json
  npm install
